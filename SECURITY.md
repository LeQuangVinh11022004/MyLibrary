# Security Policy

## Supported versions

Security fixes are applied to the latest code on the `main` branch. Older releases or deployments may not receive security updates.

## Reporting a vulnerability

Please do not disclose security vulnerabilities in public issues, discussions, or pull requests.

If GitHub's private vulnerability reporting is enabled for this repository, use the **Report a vulnerability** option on the repository's Security page. If it is unavailable, contact the repository owner privately through their GitHub profile and include:

- A short description of the affected component and potential impact.
- Steps to reproduce the issue in a project or account you own or are authorized to test.
- Any relevant versions, logs, or screenshots with secrets and personal data removed.

Please allow the maintainer reasonable time to investigate and coordinate a fix before public disclosure. Do not access, modify, or retain other users' data while investigating.

## Response

The maintainer will acknowledge reports when possible, investigate the reported impact, and coordinate remediation and disclosure with the reporter.
